Project Overview

This project is a small-business network infrastructure design for a coffee shop environment.

The goal is to create a segmented and manageable network using a Cisco router and multilayer switch. Different types of devices are separated into VLANs so that management devices, point-of-sale equipment, guest wireless clients, and network management traffic can be organized separately.

The current project focuses on the switch configuration and VLAN infrastructure. Router configuration and inter-VLAN routing will be added as the next phase.
